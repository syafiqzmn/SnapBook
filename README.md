# SnapBook – Photography Booking System

SnapBook is a web-based photography booking system developed to simplify the process of booking photography services and managing customer reservations.

## Features

**Customer**
- Register and access customer dashboard.
- View available photography packages.
- Make photography bookings.
- View booking history and status.
- Browse photography portfolio.

**Admin**
- View booking statistics and dashboard charts.
- Manage customer information and bookings.
- Add, edit and manage photography packages.
- Update booking status.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js
- Local Storage
